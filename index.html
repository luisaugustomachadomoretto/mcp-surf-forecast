Connect in 30 seconds

Point your MCP client at the live HTTP endpoint — no install required.

{
  "mcpServers": {
    "surf-forecast": {
      "url": "https://mcp-surf-forecast.fly.dev/mcp"
    }
  }
}

Add this to your client's mcp.json (Claude Desktop, Cursor, Kiro, …) and start asking about waves.
